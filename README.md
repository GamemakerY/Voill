# Voill

Ditch the keyboard and type with your voice!

## Tech Stack
- **Frontend:** React, TypeScript, Tailwind CSS (ShadCN)
- **Desktop Framework:** Tauri (for lightweight, system-level execution)
- **Backend:** FastAPI, Python
- **AI Integration:** Large Language Model (LLM) for processing speech inputs (Groq API support for now)

(This ReadMe and the project are work in progress; the first version is planned to be released soon. Stay tuned!)
